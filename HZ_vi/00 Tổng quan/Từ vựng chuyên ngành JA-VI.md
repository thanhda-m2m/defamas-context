# Từ vựng chuyên ngành JA-VI

Mục tiêu của note này là giữ `duolanguage (ja-vi)` cho các thuật ngữ chuyên ngành trong toàn bộ wiki PPES.

## Nhóm nghiệp vụ chính

- `設備機器` -> thiết bị / máy móc
- `保全` -> bảo trì
- `保全予約` -> đặt lịch bảo trì
- `実績` -> kết quả thực hiện / thực tích
- `履歴照会` -> tra cứu lịch sử
- `在庫` -> tồn kho
- `管理` -> quản trị

## Nhóm master / cấu hình

- `基本情報` -> thông tin cơ bản
- `権限` -> phân quyền
- `ユーザ管理` -> quản lý người dùng
- `拠点` -> cơ sở / địa điểm
- `エリア` -> khu vực
- `設備グループ` -> nhóm thiết bị
- `設備項目` -> hạng mục / trường thiết bị
- `メーカー` -> hãng / nhà cung cấp
- `メールテンプレート` -> mẫu email
- `基本設定` -> cấu hình cơ bản

## Nhóm dữ liệu thiết bị

- `設備ID` -> mã thiết bị
- `設備名称` -> tên thiết bị
- `機番` -> mã máy / số máy
- `設置ロケーション` -> vị trí lắp đặt
- `設置場所・建屋` -> line / khu vực / tòa nhà lắp đặt
- `階・部屋` -> tầng / phòng
- `設備状態` -> trạng thái thiết bị

## Nhóm bảo trì

- `保全情報` -> thông tin bảo trì
- `定期` -> định kỳ
- `突発` -> đột xuất
- `再発` -> tái phát
- `改善` -> cải tiến
- `保全カレンダー` -> lịch bảo trì
- `開始日` -> ngày bắt đầu
- `終了日` -> ngày kết thúc
- `担当者` -> người phụ trách
- `副担当` -> người phối hợp

## Nhóm tồn kho

- `在庫区分` -> loại tồn kho
- `型式` -> model / mã kiểu
- `品名` -> tên vật tư
- `在庫数` -> số lượng tồn
- `下限在庫数` -> mức tồn tối thiểu
- `棚番` -> mã kệ
- `発注状況` -> trạng thái đặt hàng

## Quy ước dùng trong note tiếng Việt

- Khi nhắc lần đầu: dùng dạng `JA (VI)`.
- Khi nhắc lại trong cùng note: có thể dùng `VI` nếu ngữ cảnh đã rõ.
- Với tên menu hoặc label UI quan trọng: ưu tiên giữ nguyên `JA` rồi giải thích `VI`.
